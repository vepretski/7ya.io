# Igor Vepretski Platform Sync Operating System (Managed via 7ya.io)

This playbook is the execution layer for syncing Igor Vepretski's public platforms using **7ya.io** as the central operating hub.

## Mission

Create one unified digital presence where:
- every profile reinforces the same positioning
- every content campaign starts at 7ya.io
- every platform drives measurable traffic and conversions back to 7ya.io

## Source of Truth Model

### Canonical Layer (Own Platform)
- **Primary asset:** `https://7ya.io`
- **Canonical content:** long-form articles, landing pages, offers, booking paths
- **Canonical conversion points:** newsletter, consultation, inquiry, product CTA

### Distribution Layer (Rented Platforms)
Use social and creator platforms as demand channels:
- X / Twitter
- LinkedIn
- YouTube
- Instagram
- TikTok
- Telegram
- GitHub
- Podcast/newsletter directories

Rule: Rented platforms generate attention; 7ya.io captures and compounds value.

## Brand Sync Standards

Apply across all active profiles.

### Identity
- Display name: **Igor Vepretski**
- Handle strategy: as close to `igorvepretski` as platform allows
- Profile image: same headshot family (versioned set: square/circle/dark/light)
- Banner image: same campaign narrative per quarter

### Bio System
- One master bio in 3 lengths: 70 / 120 / 200 chars
- Same category keywords across platforms
- One CTA per bio (avoid multiple conflicting CTAs)
- Primary link always `https://7ya.io`

### Voice and Messaging
- Tone: practical, strategic, clear, no hype
- Message spine: "insight -> framework -> action"
- Offer naming: identical labels across channels and on-site pages

## Managed Link Architecture (7ya.io)

All outbound campaign links should be managed under 7ya.io conventions:
- `/go/<campaign>` for public short links
- `/offers/<offer_name>` for conversion destinations
- UTM standard required on every external post

Recommended UTM contract:
- `utm_source=<platform>`
- `utm_medium=social`
- `utm_campaign=<campaign_slug>`
- `utm_content=<format_or_hook>`

## Publishing OS

### Weekly Cadence (Core)
1. Publish one anchor asset on 7ya.io.
2. Produce derivative assets for each platform.
3. Schedule releases in a 24-48h coordinated window.
4. Route engagement and traffic back to the anchor page.
5. Log KPI outcomes and iterate next week.

### Content Derivative Matrix
- 7ya.io article -> LinkedIn insight post + X thread + email excerpt
- Video lesson -> YouTube long + 3 Shorts + 2 Reels/TikToks
- Product/case update -> synchronized short-form announcement across all channels
- FAQ reply -> knowledge-base block on 7ya.io + social snippet

### 30/60/10 Mix
- 30% authority content (teach)
- 60% trust content (proof, case, behind-the-scenes)
- 10% direct offer content (CTA)

## Platform Execution Specs

### X / Twitter
- 4-7 posts/week
- 1-2 threads/week linked to 7ya.io anchor pages
- pin current campaign post and refresh monthly

### LinkedIn
- 3-5 posts/week
- 1 carousel or document post/week
- featured section always includes latest 7ya.io offer page

### YouTube
- 1 long-form video/week
- 3-5 shorts/week
- first line in description points to mapped 7ya.io page

### Instagram / TikTok
- 4-6 short videos/week
- standardized hook library + CTA subtitle format
- link-in-bio must map to current campaign hub on 7ya.io

### Telegram
- 3-7 concise updates/week
- weekly digest links to all newly published 7ya.io assets

### GitHub
- keep profile README aligned with current positioning
- link docs, demos, and project CTAs back to 7ya.io

## Governance and Roles

- **Owner:** Igor Vepretski
- **Control plane:** 7ya.io
- **Publishing authority:** content starts at 7ya.io, then distributed
- **Change policy:** profile/bio/link changes require same-day propagation to all platforms

## Operations Checklist

### Initial Alignment Sprint (Week 1)
- [ ] Audit all accounts and confirm ownership/security (2FA, recovery email)
- [ ] Normalize display name, profile photo, and banner assets
- [ ] Standardize bios using 70/120/200-char variants
- [ ] Replace all profile links with `https://7ya.io` or campaign-safe `7ya.io/go/*`
- [ ] Implement UTM schema and verify attribution capture

### Ongoing Weekly Ops
- [ ] Publish anchor content on 7ya.io
- [ ] Repurpose and schedule platform-specific derivatives
- [ ] Validate all CTAs and links post-publish
- [ ] Respond to high-intent comments/DMs with mapped resources
- [ ] Record KPI snapshot in reporting tracker

### Monthly Control Review
- [ ] Profile drift review (name, bio, links, visuals)
- [ ] Campaign attribution QA (source/medium/campaign accuracy)
- [ ] Top-performing topic analysis
- [ ] Underperforming channel remediation plan

## KPI Framework

### North-Star Metrics (on 7ya.io)
- Qualified inquiries
- Booked calls / consultations
- Email/newsletter growth
- Offer page conversion rate

### Platform Metrics (leading indicators)
- Reach / impressions
- Saves and shares
- Profile clicks
- Link CTR to 7ya.io

### Review Rhythm
- Weekly: tactical optimization
- Monthly: channel allocation decisions
- Quarterly: repositioning and campaign architecture refresh

## Incident Playbooks

### If Brand Mismatch Is Found
1. Update master profile spec.
2. Correct all out-of-sync channels within 24 hours.
3. Log root cause (manual error, automation drift, stale template).

### If Campaign Performance Drops
1. Identify weakest step: hook, retention, CTA, or landing conversion.
2. Run one-variable test for 7 days.
3. Promote the winning variant across all platforms.

## Definition of Done

All Igor Vepretski platforms are synced when:
1. Identity standards are matched on every active profile.
2. Every profile routes to 7ya.io-managed destinations.
3. Current campaign assets are published in a coordinated cross-platform window.
4. 7ya.io analytics can attribute traffic and conversion by platform and campaign.
5. A weekly KPI review and monthly drift audit are continuously maintained.
