# Entity Proof Layer

Core rule:

> כל עמוד חייב להוכיח Entity, לא רק לתאר Entity.

## Definition of Done

Every strategic page on 7ya.io must include:

1. Identity  
   Clear entity name, alternate names, role, and canonical URL.

2. Context  
   Why this entity exists, what problem it solves, and where it fits in the 7YA / StartOn graph.

3. Evidence  
   Visible proof: press links, videos, screenshots, photos, metrics, public profiles, documents, timeline, quotes, or partner references.

4. Graph Links  
   Internal links to related 7ya.io pages and external links to authoritative public profiles or official project sites.

5. Schema  
   JSON-LD that reflects only content visible on the page.

6. CTA  
   One primary action: contact, partnership inquiry, press kit download, write “7”, donation click, or article continuation.

7. Measurement  
   One GA4/GTM event connected to the main action.

## Non-negotiable

Do not add schema claims that are not visible on the rendered page.

## Success Test

A reviewer should open any core page and immediately understand:

1. Who or what is the entity?
2. What proves it?
3. What is it connected to?
4. What action should the user take?
5. How is that action measured?
